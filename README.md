# mlx-create

Native macOS app (26.2+, Apple Silicon, 16 GB min) for local image and video generation: uncensored, a one-time purchase, and nothing to learn (see `STRATEGY.md`). The app drives a bundled, pinned, stock upstream [mlx-serve](https://github.com/ddalcu/mlx-serve) binary over localhost HTTP/SSE. No inference runs in the app process.

Currently: the text-to-image slice only. Source of truth is `docs/HLD.md` (decisions `D*`). Rules and gotchas are in `AGENTS.md`.

## Stack

- Swift 6 (strict concurrency), SwiftUI with AppKit bridges, GRDB/SQLite (FTS5)
- SwiftPM library targets: `MCEngine`, `MCGeneration`, `MCCatalog`, `MCModels`, `MCLibrary`, `MCApp`, plus the `mc-catalog` tool
- Xcode project generated by XcodeGen from `project.yml`
- Engine: mlx-serve, pinned in `engine.lock` and embedded by `scripts/embed-engine.sh`

## Run the dev app

```sh
brew install xcodegen          # once (2.46+)
xcodegen generate
xcodebuild -project MLXCreate.xcodeproj -scheme MLXCreate \
  -configuration Debug -derivedDataPath build build
open build/Build/Products/Debug/mlx-create.app
```

The build embeds the engine automatically (post-compile script). You can also open `MLXCreate.xcodeproj` in Xcode and press Run.

You need at least one model installed. The smallest for smoke tests is FLUX.2-klein 4B 4-bit (about 5 GB).

## Tests and catalog

```sh
swift test                                                    # library tests
swift run mc-catalog verify Sources/MCCatalog/Resources/catalog.json
```

`MLXC_ENGINE_BIN` enables the real-engine tests.

## File size budget

A pre-commit hook (`scripts/check-file-size.mjs`, run by lint-staged through husky) refuses a source file over 8,000 tokens (bytes / 4), unless the file was already over budget and did not grow. Split by concept instead. A file that only reads whole may opt out with `@ratchet-files-ignore: <why>` in a comment within its first 10 lines. Run `node scripts/check-file-size.mjs --help` for the rules and `--all` for the backlog.

A clone needs `npm install` once, which installs the hook (Node 18.3+).

## Gotchas

- The app is single-instance (`Engine/app.lock`).
- If you kill the app with SIGTERM, run `pgrep mlx-serve` and kill any leftover engine.
- Never write to `~/.mlx-serve`. The engine runs with `HOME=<AppSupport>/Engine`.
