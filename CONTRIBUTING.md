# Contributing

Thanks for your interest in mlx-create.

**Outside contributions aren't accepted for now.** Pull requests from people outside the project will be closed without review. Fearless Holdings keeps sole copyright so that the project's licensing stays flexible (D53 in `docs/HLD.md`).

Bug reports and feature requests are welcome as GitHub issues.

If this changes, contributions will need a contributor licence agreement, and this file will say how to sign it.
